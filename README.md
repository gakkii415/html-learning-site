# タグの練習帳

コードを書き、すぐに結果を見ながらHTMLの基本タグを学べる、日本語の初心者向け学習サイトです。

## できること

- 6つの短いレッスンでHTMLの文書構造と主要タグを学ぶ
- 入力したHTMLを画面右側ですぐにプレビューする
- ミッションを満たしているか、その場で確認する
- コードと進み具合をブラウザに保存する
- スマートフォンではコードとプレビューを切り替えて学ぶ

## ローカルで動かす

Node.js 22.13以上を用意し、次を実行します。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

## ビルド

```bash
npm run build
```

## 技術構成

- Next.js互換のVinext
- React / TypeScript
- CSS
- localStorage（学習コードと進み具合）

バックエンド、アカウント登録、外部データベースは使用していません。入力したコードのプレビューは、スクリプト権限を与えないsandbox iframe内で表示します。
